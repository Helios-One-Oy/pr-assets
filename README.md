# Helios One PR assets

This public repository stores reviewed images, GIFs, and videos used as visual
evidence in Helios One pull requests.

Assets are intentionally public and listed on the
[`pr-media-1`](https://github.com/Helios-One-Oy/pr-assets/releases/tag/pr-media-1)
release. Never upload customer
data, secrets, private logs, internal documents, or unreviewed browser or
desktop captures. Asset filenames are randomized before upload so local names
do not leak, but randomness does not make the media private.

The canonical uploader and safety workflow live in Touko's private
`agent-infra` control plane. This repository contains no application code,
credentials, GitHub Actions, or customer data.
